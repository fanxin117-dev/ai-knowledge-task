## 如何使用这套文档

- 每读完一篇，打开文档里提到的代码文件，对照阅读。
- 遇到不懂的语法，先看“Python 类比”，再回到 TypeScript 代码。
- 每篇末尾都有练习任务，建议真的改一行代码、跑一次测试。
- 不要急着扩展功能。先能解释清楚现有代码的数据流，再继续写新功能。
